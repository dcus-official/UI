# Mintrinoa & OBS System

---

## Overview

**Mintrinoa** is a Roblox UI script suite powered by the **OBS System** (Object Bypassing System).  
OBS System is a dynamic UI element creation and management layer built on top of [LinoriaLib](https://github.com/violin-suzutsuki/LinoriaLib),  
featuring a unique randomized naming convention and anti-detection capabilities.
